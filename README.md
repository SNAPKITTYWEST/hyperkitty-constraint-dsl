## What is the HyperKittyConstraintDSL

A formal, constraint-first specification language for deterministic agent systems.

**Core principle:** Instead of prompting an agent "build X", you define the constraint universe first. The agent becomes a compiler/executor against a formal contract.

```
DOMAIN DEFINITIONS
      ↓
BOOLEAN ALGEBRA (NAND-complete)
      ↓
REFINEMENT TYPES  (active => trusted, entropy <= 0.20)
      ↓
DAG TOPOLOGY
      ↓
TRANSFORMATION RULES
      ↓
VALIDATION / PROOF
      ↓
GENERATED OUTPUT
```

**The validity predicate:**
```
V(l_i) = 1 IFF:
  (dA + dE == dL + dR)              -- accounting balance
  AND (I(S_t) == I(S_{t+1}))        -- invariant preserved
  AND (entropy(l_i) <= 0.20)        -- entropy gate H <= 0.20 nats
  AND (proof(l_i) == true)          -- proof certificate required
```

## Why H <= 0.20 nats

The entropy bound H <= 0.20 nats was chosen to separate deterministic from
probabilistic routing. Any agent state with entropy above 0.20 is rejected.

**The K3 result:** The K3 algebraic surface has Hodge numbers 1,0,0,1,20,1,0,0,1
(sum=24). Shannon entropy of this distribution = **0.8314 nats > 0.20**.
K3 surfaces are formally rejected by the DSL. Proved in HOL Light: `hol/k3_entropy.ml`.
